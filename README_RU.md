# S.T.A.L.K.E.R. PDA — публикация через GitHub Pages

Это статическое веб-приложение: HTML, CSS и JavaScript уже находятся внутри `index.html`. Сборка, сервер, база данных и платный домен для публикации не требуются.

## Публикация через GitHub Pages (без командной строки)

1. Войдите в свой аккаунт GitHub.
2. Создайте новый репозиторий, например `stalker-pda`. Для бесплатного GitHub Pages репозиторий должен быть публичным.
3. На странице репозитория нажмите **Add file → Upload files**.
4. Перетащите в репозиторий `index.html` и `.nojekyll` из этой папки. `README_RU.md` можно загрузить по желанию.
5. Внизу страницы загрузки нажмите **Commit changes**.
6. Откройте **Settings → Pages**.
7. В разделе **Build and deployment** выберите **Deploy from a branch**.
8. В поле Branch выберите `main`, а в папке — `/(root)`, затем нажмите **Save**.
9. Подождите несколько минут. В разделе **Settings → Pages** появится адрес сайта. Обычно он выглядит так: `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/stalker-pda/`.

## Важно о сохранениях

- GitHub Pages публикует файлы сайта, но не синхронизирует игровые сохранения между устройствами.
- Сохранения приложения хранятся локально в браузере и на конкретном устройстве. Компьютер и iPad будут иметь независимые сохранения.
- Перед очисткой данных Safari или браузера экспортируйте сохранение из КПК и храните файл отдельно.
- Не загружайте экспортированные сохранения в публичный репозиторий: они не нужны для работы сайта.
- Не размещайте в репозитории личные данные. Содержимое опубликованного сайта доступно посетителям.

## Обновление сайта

Чтобы обновить приложение, откройте репозиторий, замените `index.html` новой версией через **Add file → Upload files**, подтвердите **Commit changes**. GitHub Pages автоматически опубликует обновление.

## Состав проекта

- `index.html` — приложение КПК; это стартовый файл, который открывает GitHub Pages.
- `.nojekyll` — отключает обработку Jekyll для статического проекта.
- `README_RU.md` — эта инструкция.
